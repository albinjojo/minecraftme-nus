# Voxel Garden

A small interactive 3D garden built with Vite, TypeScript and Three.js.

## Development

Use Node.js 24.

```sh
npm ci
npm run dev
npm run build
npm test
```

Production files are generated in `dist/`.

## Controls

WASD or arrow keys move the character. Drag to rotate the camera. Mobile devices use the on-screen joystick. Escape pauses; R returns to the entrance.

## Configuration

Scene settings are in `src/config.ts`.

Third-party notices and asset licenses are documented in `ASSET_LICENSES.md` and `THIRD_PARTY_NOTICES.txt`.
